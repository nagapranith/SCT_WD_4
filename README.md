# 📝 Professional To-Do Application

A clean and minimal Task Manager Web Application built using HTML, CSS, and Vanilla JavaScript.

This project demonstrates dynamic task management with a professional dark-themed interface.



## 🚀 Project Overview

The Professional To-Do Application allows users to:

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Manage tasks dynamically in real time

The application uses JavaScript DOM manipulation to create, update, and remove tasks interactively.



## ✨ Features

- Add new tasks instantly
- Mark tasks as completed (strike-through effect)
- Delete tasks
- Responsive centered layout
- Professional dark UI theme
- Simple and user-friendly interface



## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and layout
- JavaScript (Vanilla JS) – Task management logic

No external libraries or frameworks are used.



## 💻 How It Works

- User enters a task in the input field.
- Clicking **Add** dynamically creates a new list item.
- Clicking on the task text marks it as completed.
- Clicking **Delete** removes the task.
- All operations are handled using DOM manipulation.

---

## ▶️ How to Run

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. Add, complete, or delete tasks as needed.
